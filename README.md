# 🧮 JavaScript Calculator

A simple and beginner-friendly calculator built using **HTML, CSS, and JavaScript**.

## 🚀 About the Project

This is my basic Calculator project, created as part of my journey in learning Web Development. It performs basic mathematical calculations with a simple user interface.

## ✨ Features

- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Clear functionality
- Simple and clean user interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```text
javascript-calculator/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## 💻 How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start using the calculator!
